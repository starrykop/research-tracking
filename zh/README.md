# 科研工作台（中文版）

本目录 `zh/` 存放「科研工作台」的**中文多语言版**单文件应用 `index.html`（当前版本 v1.0.4）。

## 界面语言

- 简体中文（zh-CN）
- 繁體中文（香港）（zh-TW，香港繁体用语：記錄 / 網絡 / 帳戶 等）
- 右上角下拉实时切换，选择持久化到 `localStorage('acadSubTracker.lang')`

> 英文界面作为独立版本，见仓库 [`../en/`](../en/)，本目录不再内置英文界面语言包。

## 功能基线

- 论文文件夹 + 多篇投稿两层数据模型
- 中英双语论文标题、作者位次 / 共一 / 通讯
- 期刊等级多选与优先级（JCR / CSSCI / CSCD / CCF / 北大核心 / EI / Scopus / 中英文普刊）
- easyScholar 期刊自动匹配（需用户自填 key）
- 学科 JCR 中英对照 combobox
- 统计图表（状态分布 / 期刊等级分布 / 已接收成果分布 / 投稿期刊 TOP 5）
- CSV / JSON 导入导出

## i18n 架构

- `I18N` 对象：按 `zh-CN` / `zh-TW` 两套语言包组织界面文案（共 181 个 key，两套完全对齐）
- `t(key, ...args)` 取界面文案；`SL(key)` 取状态标签（投稿 / 论文状态）的多语言文案
- 静态 HTML 文案用 `data-i18n` 属性 + `applyStaticI18n()` 统一刷新
- `setLang()` / `initLangSwitch()` 负责切换与初始化
- 每篇论文的「标题语言」（中文 / 英文 / 双语）是**数据字段**（`p.lang`），与界面语言无关

## 使用

直接用浏览器打开 `index.html` 即可，无需联网、无需服务器。数据仅存本机浏览器。

## 隐私

本工具不收集、不上传任何数据。easyScholar 密钥由你自填，只保存在本机浏览器，不会发送给作者。
